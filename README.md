## 1. نبذة عن المنصة

منصة تعليمية وتطبيقية تفاعلية مصممة خصيصاً للتحول المهني من رئاسة فرق الـ SEO والحلول البرمجية إلى إدارة المنتجات الرقمية (Product Management) في شركات البرمجيات كخدمة (SaaS) وحلول الذكاء الاصطناعي (AI Products).

تستند المنصة إلى خلفية واقعية تشمل تأسيس منتج SaaS حقيقي (**SEO GPS**) وإدارة منصات إقليمية كبرى (**منصة Ajeek** للسوق السعودي) والعمل في شركة **Digital Bond**.

## 2. مميزات المنصة الرئيسية

1. **لوحة تحكم تفاعلية متكاملة (Interactive Dashboard):**
   - حساب فوري لنسبة التقدم وساعات الاستثمار (336 ساعة موزعة على 24 أسبوعاً).
   - حفظ حالة التقدم محلياً وعبر واجهة برمجية (Local Storage & Python REST API).
2. **مصفوفة تقييم الكفاءات وتحليل الفجوات (Skills Gap Matrix):**
   - تحليل 14 كفاءة أساسية وتصنيفها إلى (قوي، متوسط، يحتاج تطوير) مع الشواهد من خبراتك وخطة سد كل فجوة.
3. **خارطة طريق الـ 6 أشهر (6-Month Strategic Roadmap):**
   - 6 مراحل تعليمية وتطبيقية متتالية، تنتهي كل مرحلة منها بمشروع عملي معتمد.
4. **دليل المصادر الحقيقية المحققة (Verified Resources Hub):**
   - جدول مصادر حية مفحوصة بالكامل (كتب، كورسات Coursera من Duke و UVA، بودكاست عربي وعالمي، مقالات Reforge و Lenny).
   - إمكانية البحث والفلترة حسب النوع والمستوى والسعر والمرحلة.
5. **الجدول الأسبوعي التفصيلي (24 أسبوعاً):**
   - توزيع المهام بمعدل ساعتين يومياً (14 ساعة أسبوعياً) مع مهام نظرية وتطبيقات عملية ومخرجات قابلة للقياس.
6. **حاسبة RICE التفاعلية (Interactive RICE Calculator):**
   - حساب فوري لدرجة RICE للميزات البرمجية مع منزلقات تحكم وترتيب تلقائي للأولويات في الـ Backlog.
7. **محاكي مقابلات إدارة المنتجات (Interview Prep Simulator):**
   - تدريب عملي على أسئلة حس المنتج (CIRCLES Framework)، وأسئلة حل الأزمات وتراجع المقاييس (Metric Drop)، والأسئلة السلوكية (STAR Framework) بأمثلة واقعية.
8. **مكتبة القوالب المعيارية (Ready-to-use PM Templates):**
   - قوالب جاهزة للنسخ بضغطة زر: وثيقة PRD، قصة مستخدم بمعايير BDD، خارطة طريق Now-Next-Later، مصفوفة RICE، وقالب دراسة الحالة للبورتفوليو.
9. **دليل أدوات الـ PM المتخصصة:**
   - شروحات وروابط رسمية لأدوات: Jira, Notion, Figma, Mixpanel, Amplitude, Miro, Productboard.
10. **دليل المسار المهني وتوحيد السيرة الذاتية:**
    - حل التضارب في البيانات الأكاديمية والوظيفية، صيغ التموضع في LinkedIn، واستراتيجية الانتقال الداخلي.

## 4. كيفية تشغيل المنصة محلياً (How to Run Locally)

### الطريقة الأولى: باستخدام Python
لا يتطلب السيرفر تثبيت أي مكتبات خارجية، ويعمل على مكتبة بايثون القياسية:
```bash
# تشغيل السيرفر على المنفذ الافتراضي 8080
python app.py

# أو تحديد منفذ مخصص (مثال: 5000)
python app.py 5000
```
ثم افتح الرابط في المتصفح:
`http://127.0.0.1:8080/`

### الطريقة الثانية: تشغيل مباشر كصفحة ثابتة (Static Web Page)
يمكن فتح ملف `index.html` مباشرة في أي متصفح ويب بدون سيرفر، وستعمل كافة الوظائف التفاعلية وتُحفظ البيانات في الذاكرة المحلية للمتصفح (localStorage).

## 5. النشر على GitHub Pages

المنصة جاهزة للنشر الفوري على استضافة GitHub Pages المجانية:
1. اذهب إلى إعدادات المستودع (Repository Settings) على GitHub.
2. اختر قسم **Pages**.
3. في خانة **Branch** اختر `main` واجعل المجلد `/ (root)`.
4. اضغط **Save** وسيكون موقعك حياً على الإنترنت برابط مخصص.
